# 🧮 My Calculator

A small browser calculator I made while learning **HTML, CSS and JavaScript**.

🔗 **[Open the live calculator](https://muneeb-pt.github.io/Calculator/)**

This started as a hands-on way to practise building a webpage and making buttons do something useful. It is not meant to be a super-advanced calculator — it is one of my early experiments with frontend development.

## What it can do

- Basic addition, subtraction, multiplication and division
- Decimal numbers and brackets
- Percentage and positive/negative toggle
- Clear and backspace buttons
- Keyboard input (numbers, operators, Enter, Backspace and Escape)
- A little result display for the previous calculation
- Responsive layout for smaller screens

## The fun bits 🎨

I wanted this one to have a bit of personality, so I kept the two original colour buttons:

- **COLOR** changes the page background to a random colour.
- **BODYS** changes the calculator body and key colours. The name is a little odd, but that is part of the original experiment!

The calculator also keeps its original playful **SAMSUG** label. These small details are intentional; I didn't want to turn a beginner project into a completely generic template.

## Built with

- **HTML** — calculator structure and buttons
- **CSS** — layout, colours and responsive styling
- **JavaScript** — button events, calculation logic and random colour changes

There is no framework, backend or external API. Everything runs in the browser.

## Run it locally

1. Clone this repository:

   `git clone https://github.com/Muneeb-PT/Calculator.git`

2. Open the project folder:

   `cd Calculator`

3. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code while editing.
